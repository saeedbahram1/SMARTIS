SMARTIS — START HERE

1) First run SETUP_SHERPA_MODELS.bat if backend\models\sherpa-fa and sherpa-en are not already populated.
2) Start Smartis with START_SMARTIS.bat, or run run_backend.bat and run_frontend.bat separately.
3) The Python backend now owns the microphone. Flutter does not use record/startStream anymore.
4) The backend keeps one microphone stream open, listens directly for commands, and pauses only while processing/TTS is active.
5) The small microphone button in the HUD restarts the backend microphone service without restarting Flutter.

Important:
- Do not copy .venv, build, .dart_tool, __pycache__, or downloaded models into the ZIP/repository.
- The Windows CMake runner is included in this package so the project can build without regenerating the runner first.
- If Windows build tools report a missing Visual C++ component, install the Visual Studio "Desktop development with C++" workload.
