SMARTIS

دستیار هوشمند صوتی ویندوز • Flutter Desktop + FastAPI Python

معماری نیتیو برنامه Desktop Application

  • Frontend: فلاتر دسکتاپ ویندوز (پوشه frontend/ با پشتیبانی کامل ویندوز)
  • Backend: سرور لوکال پایتون FastAPI روی پورت 127.0.0.1:8765
  • تشخیص گفتار صوتی: آنلاین با Google STT و آفلاین با Whisper

اجرا در سیستم محلی ویندوز Local Windows

  • برای اجرای سرور بک‌اند: فایل run_backend.bat را اجرا کنید.
  • برای اجرای رابط کاربری فلاتر: فایل run_frontend.bat را اجرا کنید.
  • برای بررسی و آماده‌سازی نیازمندی‌های صوتی: فایل INSTALL_GOOGLE_AUDIO.bat در دسترس است.
